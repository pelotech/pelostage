# pelostage

Pelotech's [Backstage](https://backstage.io) developer portal:
<https://pelostage.pelo.tech>.

```sh
direnv allow
yarn install
yarn setup
yarn dev   # http://127.0.0.1:3000
```

See [docs/README.md](docs/README.md) for setup prerequisites, configuration,
releases and deployment. The same page is published in the portal through
TechDocs.
